# Terraform — infrastructure VMware de laboratoire

Notes de projet sur la gestion de machines Debian dans VMware Workstation avec Terraform. L’exercice couvre le cycle de vie de l’infrastructure, du modèle initial au retrait des ressources.

## Documents

- [Compte rendu du projet](Projet%20Terraform.md)

## Parcours

1. Préparer le modèle Debian et définir les paramètres des machines.
2. Initialiser le fournisseur et relire le plan avant le déploiement.
3. Vérifier le démarrage des machines et l’accès au service depuis le réseau du laboratoire.
4. Retirer les ressources du TP et contrôler l’état Terraform.

Ce dépôt contient la documentation du projet. Une exécution nécessite une configuration Terraform et un environnement VMware adaptés.
